# Appletini Invasion

An original fixed-shooter game for an enhanced Apple //e running in
Appletini accelerated mode. It is intentionally built as a hardware showcase:

- 65C02 code generated by cc65/ca65;
- Appletini `$C074` accelerated-speed release (tested at GSSquared's 14.3 MHz);
- woven DHGRi using both DHGR page pairs and the `A2Li` mode-1 marker;
- Video-7 MIX/COL140M selection for crisp monochrome HUD/title text while
  preserving the playfield's DHGR color;
- a 48-particle, three-depth vertical parallax starfield moving at 1x/2x/4x
  speed in true 384-line woven coordinates;
- tear-free 30 Hz A2Li game/screen transactions with a quiet settling frame
  for physical Appletini, while speech, sound, and replay capture stay 60 Hz;
- an eight-projectile pool with Apple //e AKD-driven hold-to-fire autofire;
- an original, continuously looping two-voice Mockingboard AY-3-8910 score,
  with fire and explosion effects isolated on the third channel;
- all AY music and effects use slot 4's high-half VIA and its no-handshake
  Port A alias, so mirrored SSI writes cannot disturb the AY bus or clear
  speech-completion CA1;
- Mockingboard SSI-263 phoneme speech, behind a small scheduler that can later
  be replaced by a Phasor-native transport;
- all 128 RamWorks banks discovered at startup, with banks 1-127 used as a
  rotating gameplay/replay recorder while bank 0 remains the DHGR aux bank.

This is new game code and original art. It does not reuse Space Invaders names,
sprites, sound, or level data.

## Build

From this directory:

```sh
make disk
```

The offline build requires cc65, Java, AppleCommander, and the canonical local
Appletini checkout at `../../../appletini-one`. The bootable SmartPort result is
`dist/Appletini-Invasion.hdv` (an 800 KB ProDOS block image). Set
`APPLECOMMANDER_JAR=/path/to/AppleCommander.jar` if AppleCommander is not at
the build script's local fallback path.

## Run in GSSquared

```sh
../../build/GSSquared.app/Contents/MacOS/GSSquared \
  appletini-invasion.gs2 \
  -ds7d1=dist/Appletini-Invasion.hdv
```

Select 14.3 MHz in GSSquared (F9 cycles speed), then boot. Appletini Invasion
writes zero to `$C074` at entry so any prior TransWarp-compatible 1 MHz lock is
released. The ProDOS boot volume and game binary are both read through the
Appletini SmartPort controller in slot 7; no Disk II controller is configured.

Controls:

- Left/Right, `A`/`D`, or `J`/`L`: set movement direction
- `S`: stop
- Space: fire; hold for continuous autofire
- `R`: restart

The fixed debug mailbox at `$0300` begins with `A13I`; the automated smoke test
uses it to validate video mode, 128-bank RamWorks access, audio/speech setup,
game progress, and input inside GSSquared.
