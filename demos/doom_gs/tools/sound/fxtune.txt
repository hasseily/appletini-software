# The ten tuned effects (tools/sound/README.md, "The ten tuned effects").
#
# fxconv.py takes each script here in place of the automatic one (flag
# bit 0 of the script). One step a line: its length in 140 Hz ticks,
# then any of tone=HZ or period=N (the AY period at 2,031,250 Hz; 0 off),
# att=DB (0-40 dB below full level in 0.5 dB steps; 40 is silent),
# noise=N (the AY noise period 1-31; 0 off). A field not given keeps its
# value; a script starts with the tone off, at 40 dB, the noise off, and
# its last step ends with "end". '#' starts a comment.
#
# First versions (milestone 11, part fxconv, 2026-10-01), written from
# the automatic scripts' per-tick states and their renders
# (build/sound/fx/*.wav): the DP's pitch contour kept, the DS's loudness
# contour smoothed into a few steps, the PC speaker's gating (a tone
# every other tick, which the automatic script turns into tone and noise
# alternating) replaced by a clean pulse. Nobody has heard them on the
# card yet: they are a starting point for the owner's ear (milestone 12).
