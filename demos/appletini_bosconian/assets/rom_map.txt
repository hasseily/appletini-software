# Appletini Bosconian -- which arcade ROM graphic makes each SPR_ entry.
# Read by tools/bosco_rom.py together with a Bosconian ROM set you own
# (make ROMS=/path/to/bosco.zip). The repository holds no Namco data.
#
# Format
# ------
#   NAME: sprite N  color C [options]      16x16 sprite N (0..63) of bos1_13.5e
#   NAME: tile N    color C [options]      8x8 tile N (0..255) of bos1_14.5d
#   NAME: tiles A B C D color C [options]  2x2 block of tiles (row-major) = 16x16
#   NAME: ?                                not mapped yet: the drawn art in
#                                          sprites.txt is used for this entry
#
# C is the arcade colour code 0..63 (the attribute the game gives the object);
# build/rom/palettes.png shows the four colours of every code, and
# build/rom/sheet.png every tile and sprite with its index. Numbers may be
# decimal or 0x hex.
#
# Options, applied in this order:
#   crop X Y W H     use only this part of the decoded graphic
#   fliph flipv      mirror; rot90 rot180 rot270 turn clockwise (square only)
#   fit              (default) crop to the opaque pixels and center them in
#                    the SPR_ box (sizes in docs/DESIGN.md section 9)
#   center           center the whole graphic; pixels outside the box are lost
#   at X Y           put the graphic's top-left corner at X,Y in the box
#
# Arcade colours are turned into the nearest entry of palette 0 (DESIGN.md
# section 3); build/rom/colors.txt lists every colour that was used.
#
# Everything below is a template: no entry is mapped until someone looks at
# the sheets. The player ship exists in the ROM in a few headings only (the
# board mirrors sprites in hardware), so most SHIP_/ITYPE_/PTYPE_ headings
# will be a base sprite plus fliph/flipv/rot90.
