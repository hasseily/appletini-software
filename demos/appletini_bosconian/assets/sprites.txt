# Appletini Bosconian -- drawn sprite art (text form), the fallback used when
# no arcade ROM set is given to make (make ROMS=... converts the original
# graphics instead, see assets/rom_map.txt). Read by tools/gen_assets.py.
# Original art, drawn for this project.
#
# Format
# ------
#   # comment                      whole-line comments and blank lines are ignored
#   sprite NAME W H                start a drawn sprite; the next H lines are rows,
#                                  each exactly W characters (one per pixel)
#   derive NAME = OP SOURCE        make NAME from an earlier sprite SOURCE.
#                                  OP: rot90 (clockwise), rot180, rot270, fliph
#                                  (mirror left/right), flipv (mirror top/bottom),
#                                  copy. Rotations need a square source.
#   derive NAME = pad SOURCE [X Y] put SOURCE (any size) into NAME's box, centred
#                                  or with its top-left corner at X,Y
#
# NAME is the SPR_ name without the "SPR_" prefix (SHIP_0, ITYPE_3, MINE ...);
# a name starting with "_" is a helper of any size that only derive lines use.
# The id list, widths and heights are fixed by docs/DESIGN.md section 9; the
# generator refuses a missing sprite or a wrong size.
#
# Pixel characters (palette 0 = the arcade colour PROM, docs/DESIGN.md
# section 3):
#   .  transparent (not drawn; inside a run it becomes black)
#   k  0 black (opaque: extends the run)
#   W  1 white          R  2 red            O  3 orange         Y  4 yellow
#   P  5 purple         M  6 pink           C  7 cyan           B  8 blue
#   b  9 brown          G 10 green          V 11 violet         d 12 dark teal
#   g 13 gold           r 14 dark red       l 15 gray
#
# A row is stored as runs from the first to the last opaque pixel; a gap of
# four or more transparent pixels on byte boundaries starts a new run, smaller
# gaps are drawn black.
#
# Headings: 0 = N (up), then clockwise: 1 NE, 2 E, 3 SE, 4 S, 5 SW, 6 W, 7 NW.
# Only N, NE and E are drawn; the rest are rotations of those three.
