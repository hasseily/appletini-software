Examples

Four programs in examples/ show the library at different sizes: a starter game to copy, an audio demo, a board check for speech and STARFALL, a complete shooter.

The starter

examples/starter/ is a small game to copy: a square that held WASD or arrow keys, or a joystick, move at thirty updates a second. A joystick button plays a tone and Q returns to ProDOS. It needs RamWorks selectors 1-3 and a slot-4 card for the clock.

/* A libtini starter: a square that held keys or a joystick move at a fixed
 * 30 updates a second, a tone on a joystick button, and Q to quit. */
#include "libtini.h"

static ti_surface screen;
static const uint16_t colors[16]={0x012,0x123,0x235,0x346,0x467,0x68A,0x9BC,0xDEF,
 0xFA6,0xD64,0x832,0x4DC,0xA8F,0xFFB,0x57A,0x9ED};
/* Three voices on one AY chip: the least audio work per update. */
static ti_audio_config audio={TI_AUDIO_MOCKINGBOARD,0,0,0,3};
/* The square's position; tests read it. The caller near arena's NEARBSS
 * holds it, outside main memory, and startup zeroes it like BSS. */
#pragma bss-name (push, "NEARBSS")
int16_t starter_x, starter_y;
#pragma bss-name (pop)

static void square(uint8_t color)
{
    ti_rect r;
    r.x=starter_x;r.y=starter_y;r.width=16;r.height=16;
    ti_gfx_rect(&screen,starter_x,starter_y,16,16,color);
    ti_gfx_present(&screen,&r,0);
}

/* WASD or arrows while held, plus the stick's calibrated directions. */
static uint8_t directions(void)
{
    uint8_t d=ti_stick_read(0),k=ti_input_held();
    if(d==TI_STICK_ABSENT)d=0;
    if(k>='a'&&k<='z')k-=32;
    if(k=='W'||k==11)d|=TI_STICK_UP;
    if(k=='S'||k==10)d|=TI_STICK_DOWN;
    if(k=='A'||k==8)d|=TI_STICK_LEFT;
    if(k=='D'||k==21)d|=TI_STICK_RIGHT;
    return d;
}

int main(void)
{
    uint8_t key=0,steps,d,buttons,last_buttons=0;
    /* The canvas, display backup and audio init's temporary storage loan
     * need 97,536 bytes: three 48,640-byte resource banks, selectors 1-3. */
    if(ti_init(1,3)!=TI_OK)return 1;
    if(ti_gfx_surface_create(&screen,320,200)!=TI_OK)return 1;
    if(ti_gfx_begin(colors)!=TI_OK)return 1;
    ti_gfx_clear(&screen,0);
    ti_gfx_rect(&screen,0,0,320,12,1);
    ti_gfx_text(&screen,8,2,"MY FIRST LIBTINI GAME",13);
    ti_gfx_text(&screen,8,190,"HOLD WASD OR ARROWS, OR USE A STICK. Q QUITS",7);
    /* The audio driver also owns the clock and joystick timer. */
    if(ti_audio_init(&audio)==TI_OK) {
        ti_audio_reserve(0);
        ti_steps_begin(ti_audio_ticks,TI_AUDIO_TICKS_PER_SECOND,30,30);
    } else ti_gfx_text(&screen,8,96,"A SLOT 4 AUDIO CARD IS REQUIRED",9);
    ti_gfx_present(&screen,0,0);
    starter_x=152;starter_y=92;square(11);
    while(key!='Q') {
        ti_audio_update();ti_input_poll();
        while(ti_input_key(&key)==TI_OK&&key!='Q'&&key!='q');
        if(key=='q')key='Q';
        buttons=ti_input_buttons()&3;
        if(buttons&&!last_buttons)ti_audio_effect(0,300,12,10,1);
        last_buttons=buttons;
        steps=ti_steps_due();
        if(!steps||steps==TI_STEPS_GAP)continue;
        d=directions();
        if(!d)continue;
        square(0);
        /* Two pixels a step, inside the play area. */
        while(steps--) {
            if((d&TI_STICK_LEFT)&&starter_x>0)starter_x-=2;
            if((d&TI_STICK_RIGHT)&&starter_x<304)starter_x+=2;
            if((d&TI_STICK_UP)&&starter_y>14)starter_y-=2;
            if((d&TI_STICK_DOWN)&&starter_y<172)starter_y+=2;
        }
        square(11);
    }
    ti_audio_shutdown();ti_gfx_end();ti_gfx_surface_free(&screen);ti_shutdown();return 0;
}
  • Memory. ti_init(1, 3) grants three banks: the 32,000-byte canvas, the 32,768-byte screen backup and audio init's temporary 32,768-byte loan need 97,536 bytes, just over two.
  • Near arena. The square's position lives in NEARBSS, outside the program's main area. The checks read it there.
  • Audio as the clock. voices 3 limits the driver to one AY chip, the least work per update. ti_audio_reserve(0) leaves every voice to effects, so the button's tone can use voice 0. If audio fails the game says so and never moves, because there is no clock.
  • Fixed steps. ti_steps_due gives the updates due; the loop skips drawing when none are, and on a gap.
  • Drawing. Each move erases the old square, draws the new one, and publishes only those two 16x16 rectangles.
  • Exit. The explicit cleanup at the end is what return alone would also do.

Build it with python tools/build.py --cc65-home D:/Repos/cc65 --game starter, or make a separate project from it with examples/starter/create.py; see Getting started.

The audio demo

examples/audio_demo.c plays the event score from assets/music.json and speaks phrases from assets/speech.json on the 40-column text screen, with no graphics and no ti_init. Its configuration enables speech and ducking: {TI_AUDIO_MOCKINGBOARD, 1, 1, 0}. Keys: 1 says READY, 2 speaks 1984 with ti_speech_number, S stops speech and Q or Esc exits. Boot build/audio_demo.po.

The speech check

examples/speech_check/ is a text-mode board check for the SSI-263. Boot build/speech_check.po; it runs for up to about 25 seconds, prints one line per test and waits for a key.

LineReports
VIA-B T2Whether the $C480 VIA's timer 2 counts. The joystick reader uses it when it does.
RAW STARTWith the driver's speech code bypassed, the SSI is started directly: which VIA raised the finished-phoneme CA1 flag, and how soon. NONE after 1.00 s means no flag came.
RAW PHONEMESThe four phonemes of READY, one at a time: how many finished, the flags each VIA showed and the total time.
MOCKINGBOARD, PHASORThe driver says READY and EXCELLENT: OK and the time, or the first error and when it came. SEEN counts finished-phoneme signals sampled before the driver took them; in Phasor mode the interrupt handler takes them first, so it stays 0.
MB+JOYSTICK, PH+JOYSTICKThe same with a joystick read every 30 ms. J gives reads and failed reads.

On F1.3.1 in standalone ONE//e mode every line fails: RAW START reports NONE, RAW PHONEMES 0/4, and each driver line TIMING AT 2.00S, because that firmware clocks the SSI only from the Apple's Q3 pin. F1.3.2, the baseline, fixes this. In the emulator every line succeeds and timer 2 does not count.

STARFALL

examples/starfall/ is a vertically scrolling survival shooter with five enemy types, four weapon levels, wingmen, overdrive, chain scoring, bombs, an eight-track song and spoken callouts. examples/starfall/README.md describes the game and its controls; a built disk is committed as examples/starfall/STARFALL.po, and it plays in a browser at appletini.org/demo/starfall. It is written entirely in C. What it shows about the library:

PartHow STARFALL does it
Code layoutgame.c and game.h are the portable simulation, also compiled for the host checks; main.c owns input, audio and drawing.
MemoryIts own layout, starfall.cfg, a copy of cfg/game.cfg without the file buffer, since it makes no file calls. The simulation state, star columns, animated palette and text buffers fill 639 of the near arena's 640 bytes. Sprite cells, speech, the song and the effect table are constants in low memory.
ErrorsEvery drawing call goes through ti_error_keep; the loop stops on ti_error_first and the text screen shows ERROR ee STEP s, the library code and the startup step.
PlayfieldA 240x184 sprite scene of up to 112 sprites with a 120-byte strip. Stars, the shield bubble and the ship's core are rectangle images; atlas sub-sprites are images inside one cell. Busy scenes list fewer stars and backdrop aircraft so every aircraft, shot and pickup fits.
InterfaceA banked canvas for the HUD, captions and panels. HUD values are opaque fixed-length text, published cell by cell. After the whole canvas is published, ti_scene_forget.
EffectsPalette entries 14 and 15 pulse for aimed bullets and shields, entry 0 flashes for bombs and hits, one ti_gfx_palette a frame.
TimingThirty updates a second from ti_steps_due; a gap or an invalid audio clock pauses the game, and resuming re-arms the clock and resets the steps.
SoundM or P picks the card. The song plays on voices 0-7 of a Phasor or 0-1 of a Mockingboard; one effect table works on both through ti_audio_effect_voice. The scene's service calls ti_audio_update.
SpeechEight prepared phrases compiled with --no-numbers, each with an on-screen caption.
InputHeld keys and taps for movement, a calibrated stick that overrides keys when deflected, J to turn the stick off, and a pause panel that shows raw stick readings.
