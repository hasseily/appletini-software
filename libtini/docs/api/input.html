The keyboard

The //e keyboard gives one character at a time through its latch at $C000, not a matrix of keys: the library cannot tell which of several held keys are down. Characters are 7-bit ASCII. Keyboard and buttons need neither ti_init nor audio.

Left arrow8Return13
Right arrow21Escape27
Up arrow11Tab9
Down arrow10Delete127

ti_input_poll

ti_error ti_input_poll(void);

If a key is waiting in the latch, clears the keyboard strobe and appends the character to an eight-character queue. Call it once a loop.

Returns

TI_OK, or TI_E_NOMEM when the queue is full; that key is lost.

ti_input_key

ti_error ti_input_key(uint8_t *character);

Removes the oldest queued character into *character.

Returns

TI_OK; TI_E_UNAVAILABLE when the queue is empty; TI_E_ARGUMENT for an unwritable pointer.

uint8_t key;
ti_input_poll();
while (ti_input_key(&key) == TI_OK) {
    if (key >= 'a' && key <= 'z') key -= 32;
    if (key == 'Q') quit = 1;
    if (key == 'P' || key == 27) toggle_pause();
}

ti_input_held

uint8_t ti_input_held(void);

The most recent key while any key is still down, or 0 when none is. The //e reports only that one key: hold A, tap Space, and the call returns Space until every key is up. Diagonals therefore need a joystick.

The latch keeps the last key's code and $C010 reports in bit 7 whether any key is down. Reading $C010 also clears the strobe, so the call reads it only when no key event is pending. A pending key counts as held and stays queued for ti_input_poll. A key that arrives between the two reads would lose its strobe; the call queues it from the latch instead.

ti_input_buttons

uint8_t ti_input_buttons(void);

Bit 0 is button 0 (Open Apple, $C061), bit 1 button 1 (Solid Apple, $C062), bit 2 button 2 ($C063). A bit is 1 while its button is pressed. Detect a press by comparing with the previous reading.

ti_input_reset

void ti_input_reset(void);

Discards every queued character.

The joystick

An Apple joystick is two paddles, timed by the //e's 558 timer: a read starts both timers with an access to $C070, and each paddle's input at $C064/$C065 stays high for a time proportional to its position. libtini measures that time against the audio driver's VIA timers, never a CPU loop, so readings mean the same at 33 MHz and in TURBO. The joystick needs initialized audio.

ti_joystick

typedef struct ti_joystick { uint8_t x, y, buttons; } ti_joystick;

Paddle 0 and paddle 1 as 0-255, about 11 microseconds of device time per unit, and ti_input_buttons() at the time of the read.

ti_joystick_read

ti_error ti_joystick_read(ti_joystick *state);

Measures both paddles. It uses VIA-B timer 2 where it counts; on a VIA whose timer 2 does not count it times windows of the running timer 1 instead, reading only its high counter byte so the clock interrupt flag is not cleared. A measurement that a clock interrupt disturbed is taken again, up to three times.

Any access to $C070-$C07F starts the paddle timers, including the RamWorks selector writes at $C073 that banked transfers make, and a 558 timer still running ignores a new start. So each read first waits, up to 4 ms, for both paddles to finish. Bank 0 transfers, which include every screen publication, do not write the selector.

Returns

TI_OKBoth axes measured.
TI_E_TIMINGA paddle was still running after 4 ms: it reads 255 and the other axis is still valid. A disconnected stick reads 255 on both.
TI_E_BUSYInterrupts disturbed every attempt; *state is unchanged. A later read can succeed.
TI_E_UNAVAILABLEAudio is not initialized.
TI_E_ARGUMENTAn unwritable state.

An axis that never finishes makes the read last about 8 ms. These are raw readings: rest position, travel and direction vary from stick to stick.

ti_stick_read

#define TI_STICK_UP     1
#define TI_STICK_DOWN   2
#define TI_STICK_LEFT   4
#define TI_STICK_RIGHT  8
#define TI_STICK_ABSENT 128
uint8_t ti_stick_read(ti_joystick *state);

Reads the stick and returns its directions as TI_STICK_* bits, measured against the stick's own rest position. If state is not NULL it receives the raw reading.

  • Rest. The first reading within 48-207 on both axes after startup or ti_stick_recalibrate becomes the rest position. Call recalibrate when the stick should be untouched, such as when a run starts.
  • Threshold. Each side starts with an assumed travel of 60 units and remembers the furthest reading seen. A direction engages beyond a third of that travel, at least 16 units, and releases at three quarters of the threshold, so a stick held near it does not flicker.
  • Unfinished axes. Once a stick has answered, an axis still running at the 4 ms limit counts as full deflection.
  • Disturbed reads. A read that interrupts disturbed keeps the last directions, or returns TI_STICK_ABSENT if no stick has answered yet.
  • No stick. Before any answer, both axes unfinished returns TI_STICK_ABSENT. After four such reads the next three seconds of audio ticks return it at once without touching the paddles, so a missing stick costs a game little.

An unwritable state also returns TI_STICK_ABSENT. The calibration is static state: the call is not reentrant, and there is one calibrated stick.

uint8_t d = ti_stick_read(0);
if (d == TI_STICK_ABSENT) d = 0;
if (d & TI_STICK_LEFT)  x -= 2;
if (d & TI_STICK_RIGHT) x += 2;
if (d & TI_STICK_UP)    y -= 2;
if (d & TI_STICK_DOWN)  y += 2;

ti_stick_recalibrate

void ti_stick_recalibrate(void);

Makes the next suitable reading the new rest position and ends any no-stick wait.

ti_mouse_read

ti_error ti_mouse_read(void *state);

Reserved for an optional AppleMouse driver. It always returns TI_E_UNAVAILABLE and never changes slot personalities.
