libtini

Timing

#include "libtini/timing.h"

Fixed-rate game updates from a device clock, and sampled display edges. This module claims no hardware: the clock comes from a source function, normally the audio driver's ti_audio_ticks.

FunctionPurpose
ti_steps_beginStart counting fixed-rate updates from a clock
ti_steps_dueThe updates due since the last call
ti_steps_resetRestart from now and drop any backlog
ti_time_beginStart elapsed-time and display-edge observation
ti_time_pollSample elapsed ticks and count display edges
ti_time_note_gapRecord that work may have hidden display edges

Types

ti_tick_source

typedef uint32_t (*ti_tick_source)(void);

A clock: a function returning a count that a real device advances at a fixed rate, independent of CPU speed, modulo 232. It must return an atomic snapshot in the foreground without changing mappings or calling libtini. ti_audio_ticks is one, at a nominal 100 ticks a second. A CPU delay loop is not a valid source.

ti_time_sample

#define TI_TIME_ELAPSED_VALID 1
#define TI_TIME_GAP           2
typedef struct ti_time_sample {
    uint32_t display_edges; /* observed 0->1 $C019 edges, a lower bound */
    uint32_t elapsed_ticks; /* modulo difference since ti_time_begin */
    uint8_t flags;
} ti_time_sample;
display_edges
Blank-to-active transitions of the //e's $C019 flag that ti_time_poll happened to see. Whole frames between two polls are invisible, so this is a lower bound, not a frame count.
elapsed_ticks
Source ticks since ti_time_begin, as an unsigned modulo difference. Zero without a source.
flags
TI_TIME_ELAPSED_VALID when a source was given. TI_TIME_GAP once anything has called ti_time_note_gap since begin; memory, graphics and storage calls set it, because their work can hide edges.

Fixed-rate steps

A game simulates at a fixed rate and draws as often as it can. These calls turn device ticks into a count of simulation steps, carry the remainder of a step over, cap the catch-up after a slow frame and report long gaps instead of inventing time. They keep their state in static variables and are not reentrant. Game loop and timing shows a complete loop.

ti_steps_begin

#define TI_STEPS_GAP 255
ti_error ti_steps_begin(ti_tick_source source, uint16_t ticks_per_second,
                        uint8_t steps_per_second, uint8_t max_steps);

Starts counting steps_per_second updates a second from source, which advances ticks_per_second times a second. The count starts from now.

source
The device clock, such as ti_audio_ticks.
ticks_per_second
The clock's rate, such as TI_AUDIO_TICKS_PER_SECOND.
steps_per_second
Updates a second, at least 1. ticks_per_second * (steps_per_second + 1) must be at most 65,535; with the 100 Hz audio clock every rate up to 255 fits.
max_steps
The most steps one call returns, 1 to 254. Time beyond it is dropped, so a slow frame slows the game instead of piling up updates.

Returns

TI_OK; TI_E_ARGUMENT for a NULL source, a zero rate or a max_steps of 0 or 255; TI_E_RANGE when the product above exceeds 65,535.

ti_steps_begin(ti_audio_ticks, TI_AUDIO_TICKS_PER_SECOND, 30, 30);  /* 30 updates a second */

ti_steps_due

uint8_t ti_steps_due(void);

The number of updates due since the previous call, 0 to max_steps. Part of a step carries over to the next call. Returns 0 before ti_steps_begin.

More than one second of ticks between two calls returns TI_STEPS_GAP (255) and restarts timing from now; a game normally pauses then. A paused audio clock, as during a file call, does not advance, so that pause is not a gap.

Only the low 16 bits of the clock are kept between calls. Before resuming after a pause that may have lasted 65,536 ticks or more (about eleven minutes at 100 Hz), call ti_steps_reset.

ti_steps_reset

void ti_steps_reset(void);

Restarts the count from the clock's current value and drops any partial step, for example when a game leaves its pause screen.

Elapsed time and display edges

ti_time_begin

ti_error ti_time_begin(ti_tick_source source, uint16_t ticks_per_second);

Starts observation. With a source, elapsed ticks count from its current value. ti_time_begin(NULL, 0) chooses display observation without elapsed time. Clears the edge count and the gap flag.

Returns

TI_OK, or TI_E_ARGUMENT when only one of source and ticks_per_second is given.

ti_time_poll

ti_error ti_time_poll(ti_time_sample *sample);

Samples the display flag once, counting an edge if it changed from blank to active since the last poll, and fills *sample. Elapsed ticks support one wrap of the 32-bit source; begin again before 232 ticks pass.

Returns

TI_OK; TI_E_UNAVAILABLE when there is no source, with the sample filled, elapsed zero and TI_TIME_ELAPSED_VALID clear; TI_E_ARGUMENT when sample is not writable near memory.

ti_time_note_gap

void ti_time_note_gap(void);

Sets TI_TIME_GAP until the next ti_time_begin. The library calls it after memory transfers, drawing, publication, storage and audio gaps; a game can call it around its own long work. It does not count missed frames.

Defined in include/libtini/timing.h, implemented in src/timing.c, src/timing_gap.c and src/timing_steps.c.
