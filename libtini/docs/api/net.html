libtini

HTTP/S and JSON

#include "libtini/net.h"

The optional HTTP/S and JSON client uses Ethernet through a new ARM SmartPort service. This feature requires firmware F1.3.3 or later with that service. It does not add a software TCP/IP stack to the Apple program. Probe it at run time; games can continue offline on older firmware.

Ownership and buffers

Call from the foreground with MAIN RAM and the normal cc65 zero page selected. The caller owns all reply buffers. START copies request bytes before it returns. RETAIN holds up to 32768 body bytes for random reads and JSON. STREAM holds 4096 bytes plus the last read for replay; use consecutive offsets. STARFALL uses 128-byte replies to limit IRQ masking. The service permits one request and takes Ethernet separately from FTP. A FIFO timeout or oversized reply disables NET and optional AMEM until program exit; do not retry an unknown POST.

Types

ti_net_request holds method, url, headers, body, body_length and retain (0 for STREAM, 1 for RETAIN). Set optional headers and an empty body to NULL. ti_net_status holds generation, state, retained, result, http_status, json_state, json_type, body_length, buffered, value_length, url_length and content_type_length. ti_net_chunk holds state, length and data. Strings and body chunks have explicit lengths; append your own NUL if you need a C string.

Results and startup delay

Function return values are local ti_error codes. After a successful poll, TI_NET_FAILED carries the signed backend result in status.result. TI_NET_RESULT_NETWORK_NOT_READY is -111: DNS or TCP setup did not finish within the 30-second request deadline. The ARM clears W5100S TIMEOUT and resends DNS, and also retries after 3 seconds without a DNS reply. It waits 200 ms between TCP connection attempts. All waits yield to the main loop and share the original deadline. A switch can report link-up before it forwards packets. A valid negative or invalid DNS reply remains -106; register I/O failures remain -102. Timeouts after TCP connects remain -107. Connection retries never send HTTP data or replay a POST. The application can offer a new attempt after -111. HTTP status 400 or 500 is still an HTTP response; inspect http_status separately.

ti_net_probe

ti_error ti_net_probe(void *reply);

Identify the slot-7 ROM and HTTP service. Borrow 64 writable MAIN bytes. Older firmware returns TI_E_UNAVAILABLE. Probe before any other network call.

ti_net_start

ti_error ti_net_start(const ti_net_request *request);

Copy one method, URL, header string and body into the service. Return after submission. START replaces the previous request. Method, URL, headers and body together can use at most 1000 bytes; the 12-byte control header uses the rest of the payload. Method length is 1 to 15 bytes.

ti_net_poll

ti_error ti_net_poll(void *reply, ti_net_status *status);

Borrow 64 writable MAIN bytes and get the current state. TI_OK means that the descriptor is valid; inspect state and the signed result for the HTTP outcome. Keep input, audio and display work running between polls.

ti_net_read

ti_error ti_net_read(uint8_t source, uint16_t offset, void *reply, uint16_t capacity, ti_net_chunk *chunk);

Read BODY, VALUE, URL or CONTENT_TYPE. Capacity is 9 to 512 bytes, including an 8-byte reply header. chunk.data points into reply until you reuse it. MORE with zero bytes means wait; END means the source ends here. SOURCE_FAILED means inspect status; LOST means the offset is outside the retained source or stream replay range. Do not let the 16-bit offset wrap.

ti_net_json

ti_error ti_net_json(const char *pointer);

Select a value in a retained JSON body with JSON Pointer. Poll until json_state changes from TI_JSON_PENDING. Read TI_NET_VALUE only after TI_JSON_FOUND. Strings return decoded UTF-8 bytes without a final NUL. Invalid JSON does not change the HTTP transport result.

ti_net_cancel

ti_error ti_net_cancel(void);

Discard the current response and queue socket cleanup. Cancellation remains available while the ARM waits for DNS or a switch port.

ti_net_available

uint8_t ti_net_available(void);

Report whether the probe passed and the client remains usable.

ti_net_last_error

uint8_t ti_net_last_error(void);

Get the last SmartPort status byte. This is separate from the signed ARM result in ti_net_status.result.

ti_net_via_hz

uint32_t ti_net_via_hz(void);

Get the selected ONE//e profile clock from the last descriptor. Zero means unknown. Pass a nonzero value to ti_audio_config.via_hz before audio starts.

Examples: build net_check for an HTTPS POST and JSON lookup.
