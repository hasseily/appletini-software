Audio

#include "libtini/audio.h"

One driver for the slot-4 Mockingboard or Phasor: the device clock, music, sound effects, AY envelopes and, on the speech page, SSI-263 phrases.

Ownership

ti_audio_init takes exclusive ownership of the slot-4 card: both 6522 VIAs and their timers, every AY chip and both SSI-263 sockets. Do not start it while another driver uses the card, and do not change the card's personality or slot assignment while it runs. It registers a ProDOS interrupt handler through the standard MLI ALLOC_INTERRUPT call; ti_audio_shutdown removes it with DEALLOC_INTERRUPT and must run before anything else takes the card. Audio does not need ti_init.

The interrupt handler is assembly. It follows the ProDOS convention (CLD first, carry clear when it claims the interrupt), counts clock ticks, notes Phasor speech completion and acknowledges the timer. It never calls C, uses zero page, maps memory or calls ProDOS. Everything else happens in ti_audio_update, in the foreground.

Voices and the clock

A Mockingboard has two AY chips, six voices: voices 0-2 are the first chip and 3-5 the second. A Phasor in its native mode has four chips, twelve voices; voice v is channel v mod 3 of chip v / 3. When a Phasor is requested but its second chip pair turns out to alias the first, the driver falls back to six Mockingboard voices; ti_audio_voices reports which.

Tone periods are AY periods for a nominal 1 MHz base clock, 0-2047. In native Phasor mode the driver doubles them so pitch stays the same.

VIA-B timer 1 runs free at the card's clock rate, independent of the CPU, and interrupts 100 times a second nominally. The handler counts these ticks in 32 bits. The actual rate is ti_audio_source_hz() / ti_audio_tick_divisor(): the default configuration assumes a 1,000,000 Hz source and a divisor of 10,000. Board calibration is pending; until a board's source is measured and set in via_hz, treat 100 Hz as nominal. On the development emulator, whose Apple bus runs at about 1.020484 MHz, the default gives about 102 ticks a model second.

ti_audio_config

typedef struct ti_audio_config {
    uint8_t personality, speech, ducking;
    uint32_t via_hz;   /* 0 assumes nominal 1 MHz; calibrate on the board. */
    uint8_t voices;    /* 0 uses every voice */
} ti_audio_config;
personality
TI_AUDIO_MOCKINGBOARD or TI_AUDIO_PHASOR.
speech
Nonzero to drive the SSI-263. With 0, speech calls return TI_E_UNAVAILABLE.
ducking
Nonzero lowers music by three volume steps while speech plays and mutes envelope voices; effects keep their volume.
via_hz
The VIA clock in hertz, 100,000 to 4,000,000; 0 means 1,000,000.
voices
Limit the driver to this many voices, rounded up to whole chips of three. Every chip is silenced at init, but each later update compares and writes only the chips that serve these voices, which saves time per update. Voices above the limit are out of range. 0 uses all six or twelve.
/* Mockingboard, speech with music ducking, nominal clock, all six voices. */
static ti_audio_config audio = {TI_AUDIO_MOCKINGBOARD, 1, 1, 0, 0};

ti_music_event

typedef struct ti_music_event { uint16_t duration, period; uint8_t voice, volume; } ti_music_event;

One step of an event score: set voice to tone period (0-2047) at volume (0-15), then wait duration device ticks before the next event. A duration of 0 lets several voices change at the same moment. tools/music.py compiles a JSON score into an array of these.

Starting and stopping

ti_audio_init

ti_error ti_audio_init(const ti_audio_config *config);

Checks that no VIA interrupt is enabled (another driver would own the card) and that a VIA answers, saves the VIA port, direction and control registers, registers the interrupt handler, selects the personality, silences every chip, sets up speech if requested and starts the clock at tick 0. Speech starts with preset 0, pitch 0x40 and rate 10, powered down until the first phoneme. The default music reservation is voices 0-2.

If a video session is active, ProDOS's AUX workspace is lent back to it around the interrupt registration, which needs a free slot and 32,768 resource bytes for the duration of the call.

Returns

TI_OKAudio and the clock are running.
TI_E_STATEAlready initialized.
TI_E_ARGUMENTAn unreadable configuration or an unknown personality.
TI_E_RANGEvia_hz outside 100,000-4,000,000.
TI_E_BUSYA VIA interrupt is enabled: something else owns the card.
TI_E_UNAVAILABLENo VIA answered, or ProDOS refused the interrupt handler.
TI_E_NOMEMDuring a video session, no slot or room for the temporary loan.

ti_audio_shutdown

ti_error ti_audio_shutdown(void);

Stops speech and music, silences every voice, powers the speech chips down, stops the clock, removes the interrupt handler, restores the Mockingboard personality and the saved VIA registers. Without active audio it returns TI_OK. ti_shutdown calls it.

Returns

TI_OK; TI_E_IO when ProDOS refuses to remove the handler: the hardware is silent with its interrupts off, but the driver keeps ownership and its code, and the only allowed audio call is another ti_audio_shutdown; TI_E_NOMEM during a video session without room for the loan, with audio still owned.

ti_audio_update

ti_error ti_audio_update(void);

The driver's foreground service. It ends expired effects, plays every score event or song row that has come due, sends at most one speech phoneme, and writes changed AY registers. When no device tick has passed since the last call and nothing asked for a write, it writes nothing, so calling it often is cheap. Call it at least once a tick for steady music; in a long draw, call it from a scene's service function or between drawing calls.

Returns

TI_OKServiced.
TI_E_STATEAudio is not initialized.
TI_E_TIMINGMore than 100 ticks since the last update, or more than 32 score events or song rows due at once: the driver marks a gap and stops music and speech. Also every call while the clock is invalid, until ti_audio_resume_clock. Also a speech phoneme that did not report completion within two seconds; see speech.

ti_audio_ticks

uint32_t ti_audio_ticks(void);

The device tick count since ti_audio_init, read atomically. It is a ti_tick_source, for ti_steps_begin and ti_gfx_budget. It does not advance during a declared gap.

ti_audio_voices

uint8_t ti_audio_voices(void);

The voices the driver serves: 12 on a native Phasor, 6 on a Mockingboard or a Phasor that answered as one, or the smaller rounded voices limit. 0 when audio is not initialized.

ti_audio_clock_valid

uint8_t ti_audio_clock_valid(void);

1 while audio runs and no gap has invalidated the clock since the last resume. A game checks it to decide when to pause.

ti_audio_source_hz, ti_audio_tick_divisor

uint32_t ti_audio_source_hz(void);
uint16_t ti_audio_tick_divisor(void);

The VIA clock rate the driver assumes, and the number of VIA clocks in one tick (the timer latch plus 2). Calibrated seconds are ticks * divisor / source_hz; use 32-bit arithmetic. Both return 0 without active audio.

Gaps

A VIA can flag one missed timer period, not several. Work that keeps interrupts masked for more than a tick, or that blocks in slot firmware, would lose ticks without anyone knowing. libtini's own file and AMEM calls bracket themselves with these two functions; a game must do the same around other blocking work.

ti_audio_mark_gap

void ti_audio_mark_gap(void);

Invalidates the clock, stops the timer interrupt, powers speech down and cancels queued phrases, cancels effects and mutes every voice. While paused, the interrupt handler declines interrupts before touching any slot I/O. Safe to call without active audio, when it only marks a display-timing gap.

ti_audio_resume_clock

ti_error ti_audio_resume_clock(void);

Re-arms the timer for a full period without clearing the count, rebases the music and speech deadlines to now and restores music volumes. Ticks did not advance during the gap: they do not measure its length. Rebase a fixed-step loop with ti_steps_reset too.

Returns

TI_OK, or TI_E_STATE without active audio.

Music voices and effect voices

ti_audio_reserve

ti_error ti_audio_reserve(uint16_t music_voices);

Sets which voices belong to music, as a bit mask (bit v for voice v); the rest belong to effects. Scores may play only reserved voices and effects only the others. After init the mask is 7, voices 0-2.

Returns

TI_OK; TI_E_STATE without audio; TI_E_RANGE for a bit at or above ti_audio_voices(); TI_E_BUSY when the change would remove a voice that the playing score or an envelope uses, or reserve a voice playing an effect. Stop those first.

ti_audio_effect_voice

uint8_t ti_audio_effect_voice(uint8_t n);

The voice number of the nth voice, counting from 0, that the reservation leaves to effects; 255 when fewer are left, which ti_audio_effect rejects. With music on voices 0-1 of a Mockingboard, effect voice 0 is voice 2; with music on 0-7 of a Phasor, it is voice 8. One table of effect voices then suits either card.

Music

There are two kinds of score. An event score is an array of ti_music_event, easy to write by hand. A pattern song repeats bars, as tracker music does, and is much smaller for real music; tools/music.py compiles one from JSON and tools/midi.py arranges one from a MIDI file. The two players are separate archive modules: a program links only the one it starts. Score data is borrowed near read-only memory until the score stops, a new one starts or audio shuts down.

ti_music_start

ti_error ti_music_start(const ti_music_event *events, uint16_t count, uint8_t loop);

Stops the current score and starts playing events from now, wrapping to the first event when loop is nonzero. Every event is checked first.

Returns

TI_OK; TI_E_STATE without audio; TI_E_ARGUMENT for a count of 0 or above 512, or events that are not readable near memory; TI_E_RANGE for an event whose voice is out of range or not reserved, whose volume is above 15 or whose period is above 2047.

ti_song_start

ti_error ti_song_start(const uint8_t *song, uint16_t size, uint8_t loop);

Plays a pattern song from tools/music.py. Track i plays on the ith reserved voice when the song starts, counting from voice 0; tracks beyond the reserved voices are not played, so a Mockingboard can play the first tracks of a song arranged for a Phasor. With loop 0 the song stops after its last order position; otherwise it returns to its loop position.

The whole song is validated before the playing score stops: header ranges, table bounds, every order entry and every pattern's bytes. A song that fails leaves the old score playing. Data formats describes the bytes.

Returns

TI_OK; TI_E_STATE without audio; TI_E_ARGUMENT for a song shorter than 8 bytes or outside readable near memory; TI_E_RANGE when no voice is reserved or the song is invalid.

#include "starfall_music.h"            /* sf_song[], SF_SONG_SIZE from tools/music.py */

/* Eight tracks on a Phasor; the lead and bass alone on a Mockingboard. */
ti_audio_reserve(ti_audio_voices() == 12 ? 0xFF : 0x03);
ti_song_start(sf_song, SF_SONG_SIZE, 1);

ti_music_stop

void ti_music_stop(void);

Stops either kind of score and silences its voices. The reservation is kept.

Effects

ti_audio_effect

ti_error ti_audio_effect(uint8_t voice, uint16_t period, uint8_t volume,
                         uint16_t duration, uint8_t priority);

Plays a tone on an effect voice at once, for duration device ticks. A new effect replaces the voice's current one when its priority is at least as high.

Returns

TI_OK; TI_E_STATE without audio; TI_E_RANGE for a voice out of range (including 255 from ti_audio_effect_voice), a period above 2047, a volume above 15, or a zero duration or priority; TI_E_BUSY when the voice is reserved for music or plays an effect of higher priority.

/* A short laser on the first effect voice, priority 2. */
ti_audio_effect(ti_audio_effect_voice(0), 150, 12, 3, 2);

Hardware envelopes

Each AY chip has one envelope generator, shared by its three voices. The envelope calls drive it on reserved music voices; they are a separate archive module, linked only when called.

ti_audio_envelope

ti_error ti_audio_envelope(uint16_t voices, uint16_t period, uint8_t shape);

Switches the voices in the mask to envelope amplitude and programs each affected chip's period and shape. Every call writes registers 11, 12 and 13, even with an unchanged shape, because writing register 13 restarts the envelope. Ducking mutes envelope voices during speech and lets the envelope run on.

Returns

TI_OK; TI_E_STATE without audio; TI_E_RANGE for an empty or out-of-range mask, a zero period, a shape above 15, or on a native Phasor a period above 32,767 (the driver doubles it); TI_E_BUSY when a voice is not reserved for music, when the call would reprogram a chip without including a voice that already uses its envelope, or for voices 0-2 on a Mockingboard with speech enabled: the SSI shares the first chip's port and can reset it, so use voices 3-5 there.

ti_audio_envelope_stop

ti_error ti_audio_envelope_stop(uint16_t voices);

Returns the voices in the mask to their score volume.

Returns

TI_OK; TI_E_STATE without audio; TI_E_RANGE for a mask bit out of range.
